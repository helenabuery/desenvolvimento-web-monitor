proteções ativas
✓
JWT Authentication
Tokens HS256 com expiração de 7 dias. Middleware valida em todas as rotas protegidas.
✓
SSRF Guard
URLs com IPs privados (10.x, 192.168.x, 127.x) são bloqueadas antes do fetch.
✓
bcrypt · senhas
Salt rounds = 12. Senhas nunca armazenadas em plain text. Hash irreversível.
✓
Rate Limiting
Máx. 10 watches por usuário. Máx. 1 scan/min por URL. Previne abuso.
✓
DOMPurify
HTML capturado é sanitizado antes de renderizar. Previne XSS via conteúdo externo.
!
HTTPS Only
Apenas https:// aceito. URLs http:// são rejeitadas na validação.
